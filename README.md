# environMENTAL Normative modelling

<img src="images/environMENTAL.jpg" alt="EnvironMENTAL" width="400" align="left"/>

This repository contains the Python scripts, test data, and links to transfer/adapt Normative Models (NM) using a Docker container.  

- **NM Demo:** [PCNtoolkit-demo](https://github.com/predictive-clinical-neuroscience/PCNtoolkit-demo)  
- **Docker container setup and demo:** See instructions in [Docker_Setup.md](Docker_Setup.md)  
- **Pre-trained normative models:** See [Links_Pretained_Models.md](Links_Pretained_Models.md)  

This work was developed as part of the [EnvironMENTAL project](https://www.environmental-project.org/).
